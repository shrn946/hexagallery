# HexaGallery - Interlocking Hexagon Widget for Elementor

HexaGallery is a stunning, interlocking hexagon image gallery widget for Elementor. It creates a modern, honeycomb-style grid that is fully responsive and packed with elegant hover effects, making it perfect for portfolios, team showcases, or creative image displays.

![HexaGallery Preview](images/h.jpeg)

## 🚀 Features

- **Interlocking Honeycomb Grid:** A unique, automatically interlocking layout that looks professional and modern.
- **Dynamic Repeater:** Easily add, remove, and reorder gallery items with custom titles and descriptions.
- **Custom Lightbox:** Built-in responsive lightbox with title and description support for a full-screen viewing experience.
- **Hover Effects:**
  - **Grayscale to Color:** Smooth transition from professional grayscale to vibrant color on hover.
  - **Scale & Lift:** Subtle 3D-style lift and zoom effect.
  - **Captions:** Elegant typography overlays using "Playfair Display" and "Montserrat".
- **Advanced Controls:** Toggle hover captions, grayscale effects, and customize animation speeds.
- **Fully Responsive:** Adapts beautifully to desktop, tablet, and mobile screens.

## 🛠️ Installation

1. **Download:** Click the green **Code** button on this repository and select **Download ZIP**.
2. **Upload:** Go to your WordPress Dashboard -> **Plugins** -> **Add New** -> **Upload Plugin**.
3. **Activate:** Choose the downloaded ZIP file, install it, and click **Activate**.

## 📖 How to Use

1. Open any page or post with the **Elementor Editor**.
2. Search for the **HexaGallery** widget in the left panel.
3. Drag and drop it into your layout.
4. In the **Content** tab, use the **Hexagons** repeater to add your images and text.
5. In the **Style** tab, customize the colors, grayscale intensity, and typography to match your brand.

## 📋 Requirements

- **WordPress:** 5.0 or higher
- **Elementor:** 3.0.0 or higher
- **PHP:** 7.0 or higher
